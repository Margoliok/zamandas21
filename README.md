# ОФ «Замандас 21» — сайт

Сайт сети семейных дворовых клубов в Астане. Статический, три языка: **kk** (по умолчанию, `/`), **ru** (`/ru/`), **en** (`/en/`).

**Живой сайт:** https://margoliok.github.io/zamandas21/ · русская версия: https://margoliok.github.io/zamandas21/ru/

## Как устроено

```
src/config.mjs   ← контакты, ссылки на Google Диск, реквизиты, WhatsApp (заполнить!)
src/build.mjs    ← все тексты на 3 языках + шаблоны страниц
src/assets/      ← styles.css, app.js
docs/            ← готовый сайт (генерируется, публикуется на GitHub Pages)
```

Сборка: `node src/build.mjs` (Node 18+, без зависимостей). Затем закоммитить `docs/`.

## Логотип
Исходник — `src/assets/logo.svg` (вектор, ~490 КБ). На сайте используются облегчённые PNG:
`logo-128/256/512.png` (шапка, футер, schema.org), `favicon-32/48.png`, `apple-touch-icon.png`, `og-image.png` (превью в соцсетях 1200×630).
При смене логотипа эти файлы нужно перегенерировать из SVG.
